## Примерные вопросы для защиты курсового проекта

### Формальное описание начального модельного представления и начальной модели объектного уровня (теория)
(320 уч пособие, разделы 2.2.1, 2.2.2)

1. Структура начального модельного представления $MP(n)= \dots$
2. Начальная модель объектного ровня (НМ2) $MP2(n) = \dots$
3. Множество параметров  $P(n) \equiv  X(n)$
4. Система предметных действия $Z2(n) \equiv Y(x)$
5. Виды бинарных связей между ПД. Упорядочивание, $LY_p(n)$
6. Виды бинарных связей между ПД. Состав, $LY_p(n)Y_q(n)$
7. Виды бинарных связей между ПД. Компоновка, $LY_q(n)/Y_p(n)$
8. Взаимосвязь компонентов НМ2 $R^{MP}_2(n)$

### Методика начального моделирования  (методика)
(разделы 4.2, 4.3)

9. Элементарные действия (ЭД). Степень формализации ЭД.
10. Базовые и типовые конструкции. 
11. Спецификации описания информационной составляющей НМ2. Столбцы и правила их заполнения
12. Спецификации описания функциональной составляющей НМ2. Столбцы и правила их заполнения
13. Спецификация D3 (форма С). Какие есть типы и выжди информации.
14. Матричные диаграммы для базовых и типовых конструкций.

(спецификации можно описывать по новому. как в пособии 320,  можно по старому, как в пособии 2000г. и в ИС-2)
